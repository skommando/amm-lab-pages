Kali setup

Kali setup

Kali was the obvious choice for my tool system. The initial setup takes a fair bit of work, so I'm recording the configurations I use most, then putting together a script to do it in one click, as far as possible.

Basic Kali installation setup, updated as I go

No network after installing Kali: add the interface manually

vi /etc/network/interfaces
# 因为用 NAT 模式，需要设置 dhcp 让动态设置 ip
auto eth0
iface eth0 inet dhcp
# 重启网络
/etc/init.d/networking restart && ip a

APT sources

Mirrors in China

# deb 是针对二进制软件包的，可以使用 apt 进行安装。
# deb-src 则针对源代码包（由下载apt-get source $package），然后进行编译。
# 如果自己编译某些软件包或检查源代码中是否有错误时，才需要源软件包。一般用户不需要包含此类存储库。
# 中科大 和 阿里云 kali 源
apt-key adv --recv ED444FF07D8D0BF6
echo "deb http://mirrors.ustc.edu.cn/kali kali-rolling main non-free contrib" >> /etc/apt/sources.list
echo "deb http://mirrors.aliyun.com/kali kali-rolling main non-free contrib"  >> /etc/apt/sources.list

Package manager

apt-get install aptitude

Security tools

MSF

It comes with MSF5, and I want to upgrade to MSF6. Running msfupdate says it is no longer supported and tells me to use apt update; apt install metasploit-framework instead.

Then it stops halfway through without an error. MSF won't open, and the upgrade hasn't worked either. I give up.

When in doubt, reinstall. That fixed it.

apt remove metasploit-framework
curl https://raw.githubusercontent.com:443/rapid7/metasploit-omnibus/master/config/templates/metasploit-framework-wrappers/msfupdate.erb > msfinstall && chmod 755 msfinstall && ./msfinstall

Miscellaneous settings

Terminal appearance

Changing this in the terminal options doesn't work: the terminal is still open, so it overwrites the changes. Close the terminal first, then edit the configuration file.

  • Icon: goterminal
  • Font: Close the terminal, then edit .config/qterminal.org/qterminal.ini.
fontFamily=Dejavu Sans Mono
fontSize=11
