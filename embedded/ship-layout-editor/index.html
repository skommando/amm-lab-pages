操作提示

空白或未选大件内拖动框选，完全包裹才选中；Shift/Ctrl单击追加。Ctrl+C/V复制粘贴组件，Ctrl+S保存，Ctrl+Shift+S另存。按住Shift拖动已选组件可锁定水平或垂直；中途按放从当前位置接续。空格拖动平移。
