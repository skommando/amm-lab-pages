KALI Deploy

KALI Deploy

自然是选择 KALI 作为工具系统，初始化的配置较为繁琐，这里例举一下常用的配置，最后整理个（尽量）一键脚本。

这里讲下 KALI 安装时基础配置，持续更新

KALI 刚装好上不了网，手动添加网卡

vi /etc/network/interfaces
# 因为用 NAT 模式，需要设置 dhcp 让动态设置 ip
auto eth0
iface eth0 inet dhcp
# 重启网络
/etc/init.d/networking restart && ip a
